# ⬟ Blueprint Demo: "Nexus Intelligent Freight"

This document provides a professional, business-centric use case designed to showcase the full power of the Blueprint AI agent pipeline. Use this during demos to demonstrate how Blueprint handles complex enterprise logic, "Wow Factor" features, and strict engineering standards.

---

## 🏗️ Demo Setup: The "Nexus" Use Case

**Company**: Nexus Global Logistics  
**Product**: The Freight Orchestrator  
**Industry**: Supply Chain / Logistics  
**Build Level**: PRODUCTION

### 📖 The Pitch (Copy-Paste this into Blueprint)
> "Build an enterprise-grade Intelligent Freight Orchestrator for Nexus Global Logistics. The platform must transition us from reactive shipping to proactive orchestration. The core problem is that 15% of our global shipments are delayed due to weather or port congestion, costing us $2M/month in SLAs. 
>
> **Requirements**:
> 1. A real-time Global Health Dashboard showing every active shipment.
> 2. Predictive Delay Detection: Integrate weather and port data to flag 'At Risk' shipments 48 hours in advance.
> 3. Autonomous Reroute Engine: The system should suggest 3 alternate routes with cost/time trade-offs.
> 4. Multi-Carrier API Integration (Maersk, DHL, FedEx).
> 5. High-security Auth (OAuth2/SSO) and a full audit log for every route change."

---

## 🎭 Recommended Demo Flow (Phases 1-8)

Follow these steps to "Wow" your audience with Blueprint's depth:

### 1. The Setup (Preparation)
- **Open Settings**: Show the **Native VS Code Settings**. Point out that Blueprint uses your own API keys for security and privacy.
- **Import Standards**: (Optional) Import a `STANDARDS.md` file to show how Blueprint respects your team's specific folder structures (e.g., Clean Architecture).

### 2. Phase 1: Identity & Brand ✦
- **The Highlight**: Look at how Blueprint extracts the "Industrial Reliability" of Nexus.
- **Check for**: Hex codes like `#1A2B3C` (Deep Navy) and `#F2C94C` (Safety Orange).
- **Pro Tip**: Mention that Phase 1 can scrape real brand tokens from an existing website if you provide a URL.

### 3. Phase 2: Scope & Solution Intelligence 🧠
- **The Highlight**: **This is the most important part of the demo.**
- **Intelligent Capability**: Look for a suggested feature like *"Contextual Congestion Alert: Scans social signals near ports to detect strikes before official news hits."*
- **The Wizard**: After approving Phase 2, the **Tech Stack Wizard** will trigger. Choose:
  - Frontend: **React** (Standard)
  - Backend: **FastAPI** (High Performance)
  - Database: **PostgreSQL** (Production Grade)

### 4. Phase 4: API Contract ⬢
- **The Highlight**: Notice how the API contract is aware of the Maersk/DHL integrations mentioned in the prompt.
- **Quality**: Check the Pydantic schemas — they include strict validation for container IDs and ISO country codes.

### 5. Phase 7: UI/UX Delight ✨
- **The Highlight**: Look at the "Wow Factor" section. 
- **Signature Delight**: Blueprint will likely suggest a *"Real-time Map Transition: Shipments don't just 'move' on the map; they follow eased Bézier paths with spring-physics tooltips."*

### 6. Phase 8: The "Just Code" Handoff 🚀
- **The Highlight**: Click **🚀 Invoke Handoff**.
- **The Magic**: Notice how the Master Prompt now contains strict instructions for the AI Coder:
  - *"Create separate API and UI folders."*
  - *"DO NOT edit the .blueprint folder."*
  - *"Start coding immediately — no asking for permission."*
- **Final Step**: Paste the Master Prompt into Antigravity or Copilot and watch it scaffold the entire `API/` and `UI/` structure in seconds.

## 🛠️ Sample STANDARDS.md (For Demo)

If you want to show how Blueprint enforces strict rules, paste this into the **"Custom Standards"** box:

```markdown
# Engineering Standards: Nexus Team
- **Architecture**: Domain-Driven Design (DDD).
- **Folders**: 
  - Backend: `API/internal/domain`, `API/internal/service`, `API/cmd/server`.
  - Frontend: `UI/src/components/atoms`, `UI/src/features`.
- **Naming**: Use camelCase for JSON, snake_case for Python variables.
- **Security**: Mandatory 2FA logic on every sensitive endpoint.
```
