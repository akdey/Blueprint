Live demos are risky—AI can be unpredictable. **Pulse CRM** is designed to be the most "Bulletproof" use case for Blueprint. It relies on **Standard Enterprise Patterns** (Project Management, Client Portals, and Dashboards) that LLMs have mastered through millions of examples.

## 🏗️ The "Fail-Safe" Input (Copy-Paste)

### Project: **"Pulse — The Executive Project Dashboard"**

**The Brief**:
> "Pulse is a professional **Project Management CRM** for digital agencies. We need a centralized dashboard to track client projects, team utilization, and financial health.
>
> **Core Requirements**:
> 1. **Executive Dashboard**: A summary view showing 4 key metrics: Active Projects, Team Utilization %, Revenue MTD, and Tasks Overdue.
> 2. **Project Workspace**: A Kanban-style board for task management with drag-and-drop status updates (To Do, In Progress, Review, Done).
> 3. **Client Portal**: A read-only view for 'Client' type users to see project milestones and download invoices.
> 4. **Resource Manager**: A view to manage 'Team Members' and assign them to projects with a capacity limit (e.g., 40 hours/week).
>
> **Technical Guardrails**:
> - **Stack**: React (Frontend) + FastAPI (Backend) + PostgreSQL.
> - **Structure**: Maintain a strict separation between the `API` (FastAPI) and `UI` (React) folders.
> - **Security**: Use JWT-based authentication with three roles: Admin, Manager, and Client."

---

## 🎯 Why this works "For Sure"

1.  **Logical Consistency**: AI is 100% reliable when generating `Relationship` schemas between Users, Projects, and Tasks. It has seen this pattern more than any other.
2.  **No Hallucinations**: Because "Project Management" is a solved problem, the AI won't invent weird physics or complex math. It will focus on **Architecture, API Routes, and UI Polish**.
3.  **UI Mastery**: Standard Dashboard layouts are the "Home Ground" of modern LLMs. You will get a perfect, clean, professional-looking UI every single time.
